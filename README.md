# TF2Pickup Desktop

Десктопный клиент для https://tf2pick-up.ru/ (Windows, x64): сайт в отдельном окне, трей, нативные
уведомления и интеграция с Team Fortress 2.

## Что умеет

- Открывает сайт tf2pick-up.ru в собственном окне, сохраняя сессию Steam-авторизации между запусками.
- Оформление в стиле FACEIT: почти чёрная палитра, фирменный оранжевый акцент, острые углы и
  condensed-типографика. Тема применяется и к сайту внутри окна, и к окнам приложения (настройки,
  чат в трее). Тему сайта можно выключить в настройках — «Тема FACEIT для сайта».
- Перехватывает кнопку **join game** (`steam://connect/...`): показывает адрес сервера, запрашивает
  подтверждение (можно включить подключение без подтверждения) и запускает TF2 через Steam.
- По желанию подключается автоматически, когда ваш сервер готов (опция «Автоподключение», STV
  не затрагивается).
- Автоматически включает **pre-ready** (по умолчанию включено) и, при отдельной опции, нажимает
  «I'm ready» в диалоге начала игры.
- После окончания матча с вами автоматически открывает выбранный режим и занимает слот выбранного
  класса (режим, класс и номер слота задаются в настройках).
- Поддерживает два способа запуска:
  - **Steam URI** (по умолчанию) — Steam сам откроет TF2 и подключится к серверу, пароль передаётся
    автоматически;
  - **steam.exe с параметрами** — если нужны свои параметры запуска TF2 (например,
    `-noforcedmparms -noforcemaccel`).
- Показывает уведомления Windows, когда начинается игра (ready up) и когда сервер готов.
- Чат прямо в трее: клик по иконке открывает небольшое окно чата у трея — там видны последние
  сообщения и можно написать в чат (отправка идёт через страницу сайта, поэтому сессия Steam и все
  ограничения сайта сохраняются). Окно закрывается по Esc или клику мимо. Дублируется в меню иконки:
  последние сообщения, «Чат в трее», «Открыть чат в приложении» и подсказка иконки.
- В меню трея настраивается автозаход после лобби: режим, класс и слот выбираются прямо из меню,
  там же видна текущая занятость слотов (сколько занято по классам и кто сидит в слотах выбранного
  класса на открытой странице очереди).
- При запуске приложения сразу занимает выбранный слот в выбранном режиме (если игрок ещё не в
  очереди и у него нет активной игры).
- Сворачивает окно в трей, запускается при входе в Windows (настраивается).
- Внешние ссылки (Twitch, Ko-fi и т.д.) открываются в обычном браузере, а авторизация Steam —
  внутри приложения, чтобы не терять сессию.

## Установка

1. Запустите `TF2Pickup Setup 1.0.0.exe` из папки `dist`.
2. Установщик создаст ярлыки в меню «Пуск» и на рабочем столе.
3. При первом запуске войдите через Steam прямо в окне приложения.

Настройки находятся в трее: правый клик по иконке → **Настройки** (или кнопка ⚙ в окне чата
в трее). Окно настроек не зависит от главного окна, поэтому открывается и тогда, когда приложение
свёрнуто в трей.

При удалении установщик завершает работающее приложение (в том числе скрытое в трее) и удаляет
папку программы вместе с настройками из `%APPDATA%\tf2pickup-desktop`.

## Сборка

Нужны Node.js 20+, npm и Inno Setup 6. Сборка установщика:

```powershell
npm install
npm run dist
```

Скрипт упакует приложение через `electron-builder`, заменит иконку exe и соберёт установщик Inno Setup.
Готовый файл появится в `dist/TF2Pickup Setup 1.0.0.exe`.

Если Node.js не прописан в PATH:

```powershell
powershell -ExecutionPolicy Bypass -File build\build.ps1 -NodeDir "C:\path\to\node"
```

Иконки генерируются из `repo/public/branding/tf2pick-up.ru/favicon.png`:

```powershell
powershell -ExecutionPolicy Bypass -File build\make-icons.ps1
```

## Как это работает

Сайт уже формирует ссылку вида `steam://connect/<ip>:<port>/<password>` для кнопки входа в игру
(см. `src/games/connect-string-to-link.ts` в репозитории бекенда). Приложение перехватывает клик по
такой ссылке и либо открывает её через Steam, либо запускает `steam.exe -applaunch 440 ...`.
Дополнительно preload-скрипт следит за `#pre-ready-up-button`, `#ready-up-dialog[open]` и кнопкой
`a.join-game-button`, чтобы нажимать нужные кнопки и показывать нативные уведомления.

Адреса очередей на tf2pick-up.ru (v5) имеют вид `/q/<slug>`: `auto-6v6`, `auto-9v9`, `auto-4v4`,
`auto-ultiduo`, `auto-ultitrio`. Приложение не хардкодит их жёстко: сначала берёт адрес из
переключателя очередей `#queue-switcher` (`data-umami-event-queue`), затем из кэша сессии, затем
проверяет HEAD-запросом и только в конце использует встроенное соответствие. Поэтому переименование
режимов на сайте не ломает автозаход.

Состояние очереди читается из `#isInAnyQueue` и `#isInCurrentQueue` (скрытые `input` в
`#queue-toolbar`), а состояние pre-ready — из `aria-pressed` у `#pre-ready-up-button`. Кнопка
нажимается только когда игрок действительно в очереди и pre-ready точно выключен: сайт сам
включает pre-ready при заходе в очередь и снимает его по таймауту, поэтому «слепые» клики его бы
отменяли.

Автозаход после лобби определяется по индикатору состояния игры (`#game-<номер>-state`: был `live`
и стал пустым/ `force-ended`) либо по исчезновению баннера `#running-game-snackbar` на странице
очереди. После этого приложение открывает адрес выбранного режима и нажимает
`#queue-slot-<класс>-<номер> button.join-queue-button`, дожидаясь снятия блокировки кнопки
(кулдаун игрока после матча). Если нужный слот занят — используется первый свободный слот этого же
класса. Тот же автозаход выполняется один раз при открытии приложения на странице очереди, если
игрок ещё ни в одной очереди.

Чат берётся со страницы сайта: `#chat-message-list` → `.chat-message` (время в `.at`, автор в
`.author`, текст в `.body`). preload отправляет последние 50 сообщений в main-процесс, который
обновляет окно чата в трее, подсказку и меню иконки. Отправка из трея подставляется в форму сайта
`#chat-prompt input[name="message"]` и отправляется её же submit — так работают авторизация,
CSRF-защита и мьюты сайта.

Занятость слотов preload собирает из `.queue-slot[id^="queue-slot-"]`: `data-player` означает
занятый слот, ник берётся из `.player-name-text`. Эти данные уходят в main (`queue:state`) и
попадают в меню трея. Настройки автозахода из меню трея сохраняются в тот же `settings.json`, что и
окно настроек.

Тема FACEIT не трогает разметку и файлы сайта: сайт написан на Tailwind v4 и берёт почти все цвета
из CSS-переменных, поэтому `theme/faceit.css` переопределяет палитру и точечно дорисовывает
компоненты (шапка, вкладки, слоты очереди, баннеры, чат). Main-процесс читает `theme/fonts.css` и
`theme/faceit.css` и вставляет их через `webContents.insertCSS` на каждом `dom-ready` — стили
применяются поверх слоёв Tailwind и переживают навигацию внутри сайта. Окна приложения (настройки и
чат в трее) используют `theme/app.css` и тот же шрифт локально. Переключатель «Тема FACEIT для
сайта» в настройках снимает и заново вставляет стили без перезапуска.

## Ограничения

- Автоматическое нажатие «I'm ready» по умолчанию выключено: решение остаётся за игроком.
- Для подключения должен быть запущен и авторизован Steam.
- Приложение не меняет код сайта и бекенда — работает только с публичным интерфейсом. Тема FACEIT
  добавляется только в окно приложения через `insertCSS` и не влияет на сам сайт в браузере.
